# Soko ChapChap Marketplace

## Overview
**Soko ChapChap** is a multi-vendor marketplace designed for Kenyan customers. Buyers can shop for various products without any fees, while sellers are charged a commission on their sales.

## Features
- Free access for users
- Seller commission on sales
- Product boosting options
- Integrated payment processing via M-Pesa

## Tech Stack
- Frontend: Next.js, Tailwind CSS
- Backend: Node.js, Express, Supabase
